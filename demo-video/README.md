# Backup Demonstration Video

This folder is intended to contain the backup video of our Broken Access Control live demonstration.

The video demonstrates:

1. Logging in as Alice.
2. Exploiting the IDOR vulnerability in the vulnerable application.
3. Accessing Bob's document by modifying the document ID.
4. Explaining the vulnerable code.
5. Demonstrating the authorization fix.
6. Repeating the same attack against the fixed application.
7. Showing that unauthorized access is denied.
